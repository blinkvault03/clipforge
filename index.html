① Video source / import

Upload a video file

Any common format: MP4, MOV, WebM, MKV, AVI, FLV, WMV, TS, 3GP, MPG and more. Formats browsers cannot play are converted to a preview copy automatically. Stream recordings (OBS, Twitch/YouTube VODs you own) work the same way.

Drop a video hereor choose a file
Up to ~2 GB (browser memory limit). Large files need free memory.
Paste a link: YouTube · Twitch · Vimeo · Kick · direct file · HLS (.m3u8)
Platform pages (YouTube, Twitch, Vimeo, Kick) give a preview only. To clip them, upload the recording or use the live capture below. Direct video and HLS links are imported for clipping when the host allows browser access.
Record a livestream you are authorised to clip

Play your live stream in another tab or window, then capture that tab (tick “Share tab audio”). ClipForge records it to a video you can analyse while or after it plays. Protected (DRM) streams capture as black, and ClipForge does not bypass protection.

⑩ Connected channels

Connect a YouTube channel

Read-only access to your channel, uploads and your own live broadcasts for preview and metadata. It does not download YouTube video files.

Setup: enable YouTube Data API v3 in Google Cloud, create an OAuth Web client and add this site’s exact HTTPS origin to authorised JavaScript origins. A Client ID is an identifier, not a password. Access tokens stay in memory only.
