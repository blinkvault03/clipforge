Not connected. Add your Google OAuth Client ID, then connect.
Setup: enable YouTube Data API v3 in Google Cloud, create an OAuth Web application client, and add the exact HTTPS site origin (or http://localhost for local development) to authorised JavaScript origins. Client ID and API key are identifiers, not passwords. OAuth access token stays in memory and is cleared on refresh/disconnect. Only connect a channel you own or are authorised to manage.
Direct media import works only when the host permits browser access (CORS) and the URL serves a video file. YouTube watch/live URLs are not direct media URLs.
